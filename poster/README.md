# CivicResolve AI poster

The poster is designed as a 3 × 4 ft portrait flex layout and can be printed directly from the HTML file.

1. Save the supplied Vignan's header/logo image in this folder as `vignans-header-logo.png`.
2. Open [civicresolve-poster-3x4.html](./civicresolve-poster-3x4.html) in Chrome or Edge.
3. Choose **Print → Save as PDF**, set margins to **None**, scale to **100%**, and enable background graphics.
4. Give the PDF to the flex-print shop at **36 × 48 inches**. For a 3 × 3 ft flex, print with proportional scaling to **36 × 36 inches** after checking the crop with the shop.

The fallback text header appears only when the supplied logo file is missing. The citizen photo area is an intentional demo placeholder; replace it with a project screenshot if desired.
